Privacy Policy

Tzippi AI Agent is a personal AI assistant, currently intended for personal, private use by its owner.

Access to Google data

Tzippi accesses Google user data only after the user grants authorization through Google's OAuth consent screen, and only for the permissions the user approves.

Google Calendar

  • Tzippi may read the user's calendar events, for example to answer questions about the user's schedule.
  • Tzippi may create, update and delete calendar events when the user requests it.

Gmail

  • Tzippi may read the user's emails to provide email-related functionality the user requests, and to perform background checks for emails the user has asked it to watch for.
  • Tzippi may create email reply drafts.
  • Tzippi sends an email only by sending a previously created draft, and only after the user explicitly approves sending it.

How Google data is used

  • Google user data is used only to provide the assistant functionality the user requests.
  • Tzippi does not sell Google user data.
  • Tzippi does not use Google user data for advertising.
  • To generate responses, conversation content, which may include information from the user's emails or calendar, is processed by an AI language model provider (OpenAI) through its API.
  • Tzippi's replies are delivered to the user through the chat interface and are stored in Tzippi's conversation history so the assistant can follow the conversation.

OAuth tokens

Access tokens and refresh tokens issued by Google are used only to maintain the Google integrations the user has authorized. The user can revoke Tzippi's access at any time from their Google Account permissions page (myaccount.google.com/permissions).
